# 验证 Skill

## 概述

用于测试完整阅读流程的验证skill。模拟从封面识别到全书总结的完整流程，生成音频和双时间线对照表。

## 验证流程

```
┌─────────────────────────────────────────────────────────────┐
│                    验证流程                                   │
│                                                             │
│  1. 识别封面 → 保存书名                                      │
│  2. 逐页识别 → 保存文字                                      │
│  3. 逐页朗读 → 保存音频                                      │
│  4. 左右页引导（双页时）                                      │
│  5. 翻页提示 → 模拟等待                                      │
│  6. 生成总结 → 朗读总结                                      │
│  7. 输出双时间线对照表                                       │
│  8. 生成完整音频文件                                         │
└─────────────────────────────────────────────────────────────┘
```

## 使用方法

```bash
node test_verification.js
```

## 输出

1. **完整音频文件**：`test_images/full_verification.wav`
2. **双时间线文件**：`test_images/verification_timeline.md`

## 双时间线设计

验证采用双时间线并行展示，一条是音频时间线（孩子听到的内容），一条是后台进程时间线（保存等并行操作）。

### 时间线A：音频时间线

记录孩子实际听到的所有内容及其时间位置：

| 时间点 | 事件 | 音频时长 |
|--------|------|----------|
| 00:00 | 欢迎语 | 4.3秒 |
| 00:04 | 第1页OCR识别（等待） | 5.2秒 |
| 00:09 | 第1页TTS朗读 | 20.6秒 |
| 00:30 | 朗读间歇 | 2.0秒 |
| 00:32 | 翻页提示 | 2.4秒 |
| 00:34 | 等待翻页（静默） | 3.0秒 |
| ... | ... | ... |

### 时间线B：后台进程时间线

记录与音频并行执行的后台操作（保存、预处理等）：

| 音频时间点 | 并行操作 | 操作耗时 |
|------------|----------|----------|
| 00:09 | 保存第1页文字到IndexedDB | 5ms |
| 00:09 | 保存第1页图片到IndexedDB | 12ms |
| 00:09 | 保存第1页音频到IndexedDB | 8ms |
| ... | ... | ... |

## 验证清单

| 步骤 | 功能 | 验证点 |
|------|------|--------|
| 封面识别 | recognition | 识别书名 |
| 页面识别 | recognition | 识别文字、忽略页码 |
| 语音合成 | reading | TTS生成音频 |
| 音色选择 | reading | 使用用户设置的音色 |
| 左右页引导 | reading | 双页时引导看左边/右边 |
| 翻页提示 | reading | "请翻下一页" |
| 音频保存 | storage | 保存到IndexedDB |
| 文字保存 | storage | 保存到IndexedDB |
| 图片保存 | storage | 保存到IndexedDB |
| 并行流程 | storage | 保存不阻塞音频播放 |
| 故事总结 | summary | 生成全书总结 |
| 总结朗读 | summary | 总结内容朗读出来 |
| 连续播放 | runtime | 音频无缝衔接 |

## 左右页引导规则

当检测到一张图片包含左右两页时：
1. 先朗读左边内容
2. 温柔引导"小朋友，该看右边了"
3. 再朗读右边内容
4. 引导语不用"左页""右页"等生硬词汇

## 并行流程说明

在真实运行中，以下操作会与音频播放并行执行：

```
音频时间线:  [朗读第1页] → [翻页提示] → [朗读第2页] → ...
                |              |              |
后台进程:    [保存文字]     [预加载下一页]  [保存文字]
             [保存图片]                       [保存图片]
             [保存音频]                       [保存音频]
```

验证脚本通过模拟保存操作的耗时，验证并行流程是否能完全跑通。
